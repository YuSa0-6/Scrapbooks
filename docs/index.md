# Scrapbooks ドキュメント

絵とコードを集めたスクラップブック風ポートフォリオの設計資料です。[Open Knowledge Format（OKF）v0.2](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md) に沿って、1 つの概念を 1 ファイルで書いています。書き方は [ドキュメントの書き方](/guides/writing-docs.md) を参照してください。

# 分類

- [プロダクト](/product/) - 何を作るか・誰のためか
- [デザイン](/design/) - 見た目・動き・3D の決まりごと
- [アーキテクチャ](/architecture/) - どう作るか（ボード・プラグイン・Effect・性能）
- [決定事項](/decisions/) - 決めたことと理由
- [ガイド](/guides/) - 手順書（ドキュメント・開発・検証・公開）
- [作業](/tasks/) - 作業の一覧
