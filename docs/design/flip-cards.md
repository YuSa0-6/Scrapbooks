# 表と裏

| カード | 表 | 裏 |
| --- | --- | --- |
| 絵 | 写真（ポラロイド／切り抜き）とタイトル | 写真の裏に書いたメモ：手書きメモ・年・タグ・「詳しく見る」 |
| 動くコード | 動いている様子（iframe） | コードの抜粋 |
| 動かないコード | コードの抜粋 | ひとこと説明・言語・タグ |

# 操作

- カードの右下に「裏返す」ボタン（`<button aria-pressed>`、名前は「〇〇を裏返す」）。44px 以上
- カード全体のリンクは、タイトルの `<a>` を `::after` で広げて作る。ボタンをリンクの中に入れない
- 裏返しは `rotateY(180deg)` を `--spring` で。面は `backface-visibility: hidden`
- 裏側の中身は、裏返すまで `inert` にして Tab で入れないようにする
- 整頓モード・動きを減らす設定では、回転せずに表と裏を入れ替えるだけ
