# 表と裏

| カード | 表 | 裏 |
| --- | --- | --- |
| 絵 | 写真（ポラロイド／切り抜き）とタイトル | 写真の裏に書いたメモ：手書きメモ・年・タグ・「詳しく見る」。`back_image` があれば、メモの上に 2 枚目の絵を大きく出す（メモは絵の下に小さく残す） |
| 動くコード | 動いている様子（iframe） | コードの抜粋 |
| 動かないコード | コードの抜粋 | ひとこと説明・言語・タグ |

# 操作

- カードの右下に「裏返す」ボタン（`<button aria-pressed>`、名前は「〇〇を裏返す」）。44px 以上
- カード全体のリンクは、タイトルの `<a>` を `::after` で広げて作る。ボタンをリンクの中に入れない
- 裏返しは `rotateY(180deg)` を `--spring` で。面は `backface-visibility: hidden`
- 角度は 180 度で固定にして、`--wobble` は掛けない。掛けると `--wobble` が 0.5（幅 640px 以下）のとき 90 度で止まり、0 のとき裏に行けないため。`--wobble` が 0 の整頓モードは、下のとおり回転を止めて面を入れ替える
- ボタンは JS が動くとき（`html.js`）だけ見える。押しても何も起きないボタンを置かない
- 幅 760px 以下や `pointer: coarse` でも回転は 3D のまま。回転を止めるのは整頓モードと動きを減らす設定だけ
- 裏側の中身は、裏返すまで `inert` にして Tab で入れないようにする
- 整頓モード・動きを減らす設定では、回転せずに表と裏を入れ替えるだけ
